# Fieldnotes
A calmer place for ideas, plans and the next small step.

> Project brief · Example document · 6 October 2026

## The idea
Build a small personal workspace that helps people move from scattered thoughts to a clear next action. The first version should feel welcoming within a minute.

### What matters most
- Capture a thought without choosing a category first.
- Keep notes and next steps together.
- Make today’s priorities easy to find.
- Keep the interface quiet and the reading area comfortable.

### First release
| Area | Included | Later |
| --- | --- | --- |
| Notes | Create, edit and search | Rich embeds |
| Planning | A short daily list | Shared projects |
| Organisation | Folders and favourites | Smart suggestions |
| Storage | Local-first saving | Optional sync |

### The experience
The main screen opens to your most recent note. A compact sidebar holds folders; the page itself is given the most space. A single action starts a new note.

The editor saves as you type and makes its status visible only when there is something to report.

### Next steps
1. Validate the capture and search flow.
2. Try the layout at desktop and phone widths.
3. Check keyboard navigation and empty states.
4. Review the first version with three people.

### Definition of done
Someone can create a note, turn it into a small plan, leave the app and find it again without instructions.
